## 🔧 ЧТО НУЖНО СДЕЛАТЬ

### ШАГ 1: Проверить слои

Убедиться, что существуют слои:
- Layer 8: Player
- Layer 9: Enemy  
- Layer 10: Weapon
- Layer 11: UI

Если нет — создать в Edit → Project Settings → Tags and Layers

### ШАГ 2: Настроить Player prefab

1. Открыть **Assets/Prefabs/Player.prefab**
2. Проверить, что есть компоненты:
   - ✅ NetworkPlayer
   - ✅ PlayerController
   - ✅ PlayerLook
   - ✅ PlayerWeapons
   - ✅ PlayerInputRouter
   - ✅ Camera (Main Camera)

3. Добавить компонент **ScopeRenderer** (если физический прицел нужен):
   - Add Component → ScopeRenderer
   - Настроить параметры (см. ШАГ 3)

### ШАГ 3: Создать материал для линзы прицела

Только если используется ScopeRenderer (физический прицел):

1. **Assets → Create → Material**
2. Назвать: `Mat_ScopeLens`
3. Shader: HDRP/Lit
4. Параметры:
   - Base Color: (0, 0, 0) чёрный
   - Metallic: 0.9
   - Smoothness: 0.95
   - Emission: включить, цвет (0.1, 0.2, 0.3)

5. В Player prefab, компонент ScopeRenderer:
   - Lens Material: перетащить Mat_ScopeLens

### ШАГ 4: Проверить оружие в сцене

В OutdoorsScene.unity:

1. Найти Player
2. Проверить, что Player содержит:
   - Main Camera (с tag MainCamera)
   - Character Controller компонент
   - PlayerWeapons компонент

### ШАГ 5: Настроить слои для моделей оружия

Любая модель оружия должна быть на слое **Weapon**:

1. В Player найти WeaponRoot → WMRifle
2. Установить Layer: **Weapon**
3. Применить ко всем дочерним объектам (Apply to Children)
4. То же для WMShotgun и всех дочерних

### ШАГ 6: Проверить NetworkPlayer

В Player prefab найти компонент NetworkPlayer:

```
isLocalPlayer — должен быть от Mirror
netId — устанавливается автоматически при спавне
```

### ШАГ 7: Запустить сцену

1. **Play** в Unity Editor
2. Проверить:
   - [ ] Оружие видно в кадре
   - [ ] ЛКМ — стреляет
   - [ ] ПКМ — прицеливание (оружие приближается)
   - [ ] R — перезарядка
   - [ ] 1/2 — переключение оружия
   - [ ] Видно прицел в центре экрана (оптический оверлей)
   - [ ] Если ScopeRenderer — на линзе видно RenderTexture

## 🎮 УПРАВЛЕНИЕ В ИГРЕ

| Клавиша | Действие |
|---------|----------|
| **ЛКМ** | Стрельба |
| **ПКМ** | Прицеливание (оружие приближается к камере) |
| **R** | Перезарядка |
| **1** | Винтовка |
| **2** | Дробовик |
| **WASD** | Движение |
| **Space** | Прыжок |
| **Ctrl** | Приседание |
| **Shift** | Спринт |
