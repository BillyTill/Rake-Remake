# 🎯 Система физического прицела винтовки — Итоговый отчёт

## 📋 Краткое резюме

Реализована **полная система оптического прицела** для винтовки в Unity 6 + HDRP:

✅ **Физическая линза** — сфера на окуляре с RenderTexture  
✅ **Отдельная камера прицела** — рендерит увеличенное изображение  
✅ **Плавное движение модели** — винтовка смещается от бедра к щеке  
✅ **Визуальные эффекты** — виньетка, хроматическая аберрация, затемнение  
✅ **Перекрестие на линзе** — баллистический крест, не UI элемент  
✅ **Гладкие переходы** — без рывков при включении/отключении ADS

## 📁 Созданные и изменённые файлы

### Новые файлы (3)

#### 1. `Assets/Scripts/Weapon/ScopeSystem.cs` (211 строк)
Основной класс для управления прицелом:
- Управляет `ScopeCamera` (отдельная камера, рендерит в RenderTexture)
- Синхронизирует FOV камеры прицела с главной камерой
- Контролирует видимость линзы и интенсивность эффектов
- Генерирует текстуру перекрестия с крестом и баллистическими рисками
- Плавно масштабирует эффекты по параметру `_adsBlend` (0..1)

**Ключевые методы:**
- `SetAdsBlend(float adsT)` — получает состояние прицеливания из PlayerWeapons
- `UpdateMaterialProperties()` — передаёт параметры эффектов в шейдер
- `BuildReticleTexture()` — процедурно генерирует текстуру перекрестия

#### 2. `Assets/Shaders/ScopeLens.shader` (124 строки)
HDRP шейдер для линзы прицела:
- Отрисовывает RenderTexture из `ScopeCamera`
- Добавляет виньетку (затемнение по краям)
- Применяет хроматическую аберрацию (радужное смещение)
- Накладывает перекрестие из текстуры
- Создаёт круглую маску окуляра (чёрная шторка за границей)
- Затемняет изображение для эффекта "запотевшего стекла"

**Параметры шейдера:**
```glsl
_ScopeRenderTexture     // Текстура из прицельной камеры
_Reticle               // Текстура перекрестия
_VignetteStrength      // Интенсивность виньетки (0..1)
_ChromaticAberration   // Интенсивность хроматики (0..1)
_LensDarkening         // Затемнение (0.5..1)
```

## 🎮 Как работает система

### Иерархия в сцене
```
Player
└─ Body
   └─ PitchPivot
      └─ Camera (Main)
         └─ WeaponRoot
            └─ WMRifle
               ├─ Scope (новый GameObject)
               │  ├─ ScopeLens (Sphere)
               │  │  ├─ Renderer (использует ScopeLensMaterial)
               │  │  └─ ScopeSystem (компонент)
               │  └─ ScopeCamera (создаётся динамически)
               │     └─ Рендерит в RenderTexture
               └─ [остальные части модели: ствол, магазин и т.д.]
```

### Поток выполнения (каждый кадр)

1. **PlayerWeapons.UpdateLocal()** (Update)
   - Рассчитывает `_adsT` (0 → 1) при нажатии/отпускании ПКМ
   - Вызывает `_scopeSystem.SetAdsBlend(_adsT)`

2. **ScopeSystem.LateUpdate()** (LateUpdate)
   - Копирует позицию/ротацию главной камеры → ScopeCamera
   - Рассчитывает FOV: `scopeFov = mainFov / Lerp(1, 2.6, _adsT)`
   - Включает/отключает ScopeCamera (`enabled = _adsT > 0.01`)
   - Обновляет параметры материала

3. **ScopeCamera рендерит в RenderTexture**
   - Каждый кадр рендерит сцену с увеличением в RenderTexture
   - Изображение "замораживается" на этапе рендера

4. **Шейдер ScopeLens обрабатывает линзу**
   - Берёт текстуру из RenderTexture
   - Применяет виньетку, хроматику, затемнение
   - Накладывает перекрестие
   - Отрисовывает на экран как часть модели винтовки

5. **PlayerWeapons.PoseLocal()** (LateUpdate)
   - Движет модель винтовки: `position = Lerp(hipAnchor, adsAnchor, _adsT)`
   - Винтовка плавно приближается к камере при ADS

## 📊 Параметры и формулы

### Движение модели винтовки
```
position = camera.position 
         + camera.rotation * aimPivot
         + aimRotation * (anchor - aimPivot)
         
where anchor = Lerp(hipAnchor, adsAnchor, _adsT)
```

### FOV прицельной камеры
```
scopeCamera.fov = mainCamera.fov / Lerp(1.0, scopeZoom, _adsT)

На ADS = 0:   fov = 60 / 1.0 = 60°      (нормально)
На ADS = 1:   fov = 60 / 2.6 ≈ 23°     (увеличено в 2.6 раза)
```

### Интенсивность эффектов
```
vignette = vignetteStrength * _adsBlend
chromatic = chromaticAberrationStrength * _adsBlend
darkening = Lerp(1.0, lensDarkening, _adsBlend)
```

## 🔧 Переменные для настройки

В Inspector компонента `ScopeSystem`:

| Параметр | Значение | Описание |
|----------|----------|---------|
| `scopeZoom` | 2.6 | Множитель увеличения прицела |
| `vignetteStrength` | 0.6 | Затемнение по краям (0..1) |
| `chromaticAberrationStrength` | 0.15 | Радужное смещение (0..1) |
| `lensDarkening` | 0.92 | Прозрачность линзы (0.5..1) |

Рекомендуемые значения:
- **Реалистичный прицел**: viagnette=0.7, chroma=0.1, darkening=0.95
- **Игровой прицел**: vignette=0.5, chroma=0, darkening=0.9
- **Ночной прицел**: vignette=0.8, chroma=0.2, darkening=0.85

## 🐛 Возможные проблемы при запуске

### Проблема 1: "Shader not found"
**Решение**: Убедитесь, что `Assets/Shaders/ScopeLens.shader` на месте, затем:
```
Assets > Reimport All Assets
```

### Проблема 2: Линза не видна
**Проверьте**:
1. Нажимаете ли ПКМ? (ADS должен быть > 0.3)
2. Есть ли `ScopeSystem` в иерархии? (должен быть под WMRifle/Scope)
3. Рендерит ли `ScopeCamera`? (Render Texture Viewer →看 ScopeRenderTexture)

### Проблема 3: Перекрестие размытое
**Причина**: Разрешение RenderTexture слишком низкое.  
**Решение**: В `WeaponModelBuilder.BuildScopeLens()` измените:
```csharp
RenderTexture scopeRT = new RenderTexture(1024, 1024, ...); // было 512x512
```

## 🎓 Технические подробности

### Почему используется отдельная камера?
- **Зум**: меняется только FOV прицельной камеры, главная остаётся неизменной
- **Реалистичность**: изображение внутри линзы увеличено, но окружение остаётся нормальным
- **Производительность**: рендеризация в RT не влияет на основной рендер

### Почему материал, а не UI?
- **Перспектива**: перекрестие вращается с моделью винтовки, как реальный прицел
- **Физичность**: линза — часть модели оружия, на которую смотрит игрок
- **Гибкость**: можно добавлять эффекты поломки, запотевания, трещин

### Почему сфера, а не плоская текстура?
- **3D реалистичность**: линза — объёмный предмет, видимый с разных углов
- **Интеграция**: естественно встраивается в иерархию модели
- **Масштабирование**: легко настроить размер и позицию
